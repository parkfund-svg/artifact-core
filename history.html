DEVELOPMENT HISTORY

개발 연혁

최근 성장 과정입니다.

2026.07 초

안정적인 리스크 관리 기반 구축

옵션 증거금·수수료를 시장별로 정밀 계산하고, 보유 포지션을 포함한 실시간 평가자산을 반영. 매매 발생 시 전후 장면을 자동으로 남기는 녹화 기능도 추가했습니다.

2026.07 중순

전략빌더 "AI 자동 개선 루프" 완성

전략을 만들면 즉시 백테스트되고, 결과를 AI가 다시 확인해 개선안을 제시하는 흐름을 완성. 캔들 해부·상위 타임프레임 분석 같은 프리미엄 노드도 이때부터 추가되기 시작했습니다.

2026.07 하순

다중 계좌 무인 자동매매 · 국면전환 전략 완성

여러 계좌를 동시에 무인으로 운영할 수 있는 인프라를 구축하고, 화면을 닫아도 계속 동작하도록 만들었습니다. 시장 국면(강세·약세·횡보)에 따라 자동으로 전환되는 전략 3종은 실전검증에서 상승국면 대응 전략 기준 모의검증(백테스트) 수익률 152%(샤프비율 2.8)를 확인했습니다 — 실계좌 실적이 아닌 모의검증 결과입니다. 같은 시기 안드로이드 앱도 출시했습니다.

2026.08

AI봇 신호 제어 · 예측봉 규칙매매

AI봇의 매매 신호를 그대로 따를지, 반전시킬지, 국면에 따라 자동 전환할지 설정하는 기능과, 예측봉을 기준으로 진입·청산을 자동 실행하는 "예측봉 규칙매매" 모드를 새로 추가했습니다. 이후 예측봉 매매 시스템을 재미나이·클로드·GPT 3중 AI 검증 구조로 확장해, 세 AI의 예측 방향이 일치할 때만 매매에 반영하도록 고도화했습니다.

2026.08

브랜드 리뉴얼 — Quantrea-X로 새 단장

회사명과 제품명을 새로 정비하고, 전면 영상 기반의 새 홈페이지로 브랜드를 리뉴얼했습니다.

2026.08

차트 UI 전면 개선

차트 화면 전반의 시인성과 조작감을 다시 다듬었습니다.

2026.08

모바일 앱 백그라운드 실행 지원

안드로이드 앱을 백그라운드에 둔 상태에서도 매매 현황 확인과 자동매매 운용이 끊기지 않도록 개선했습니다.
