HATS란? Hybrid AI Trading System

LLM의 전략 설계 지능(Brain)과 Local ML의 실행 속도(Hand)를 Artifact로 연결한 하이브리드 AI 자동매매 시스템입니다.

💡 HATS의 핵심 개념

Brain (두뇌)

LLM이 자연어 전략을 분석하여 실행 가능한 논리로 설계

Artifact (설계도)

설계된 전략을 JSON으로 영구 저장하여 재사용

Hand (실행)

Local ML이 초고속으로 신호 생성 및 매매 실행

✨ HATS의 핵심 장점

초저비용

LLM 1회 사용 후 무한 실행, 토큰 비용 최소화

초저지연

수 ms 단위 실행 속도, 실시간 시장 대응

자연어 전략

코딩 없이 말로 전략 생성 가능

안정성

검증된 Artifact 재사용으로 일관성 보장

⚖️ 기존 시스템 vs HATS 비교

❌ 기존 LLM 자동매매의 문제

  • 높은 운영 비용: 매 실행마다 LLM 호출로 토큰 비용 급증
  • 느린 실행 속도: 수 초 지연으로 슬리피지 발생
  • 비일관성: 같은 입력에도 다른 결과 가능
  • API 의존: 네트워크 장애 시 중단

✅ HATS의 해결책

  • 초저비용: LLM 1회 사용 후 Artifact 무한 재사용
  • 초고속: Local ML로 수 ms 단위 실행
  • 일관성: 동일 Artifact로 예측 가능한 동작
  • 독립 실행: 로컬 환경에서 안정적 작동

🔄 HATS 작동 프로세스

1단계 · 전략 입력 (Brain)

"RSI 30 이하면 매수, 70 이상이면 매도" 같은 자연어로 전략 설명

2단계 · Artifact 생성

LLM이 전략을 분석하여 JSON 형태의 실행 설계도로 변환 및 저장

3단계 · 실시간 실행 (Hand)

Local ML이 Artifact를 읽어 시세/호가 분석 후 초고속 매매 신호 생성

4단계 · 무한 반복

동일 Artifact로 추가 LLM 호출 없이 지속적 자동매매 (토큰 비용 0원)

자주 묻는 질문

왜 HATS가 비용 효율적인가요?

실행 단계에서 LLM을 호출하지 않습니다. 초기 설계 시 1회만 사용하고, Artifact를 무한 반복 실행하므로 토큰 비용이 발생하지 않습니다.

실행 속도는 어느 정도인가요?

Local ML 최적화로 수 밀리초(ms) 단위의 저지연을 목표로 설계되었습니다. 시장 급변에도 신속하게 대응합니다.

전략 빌더는 어떻게 동작하나요?

자연어로 기술한 매매 규칙을 노드 그래프로 변환하고, Artifact(JSON)로 표준화하여 백테스트 및 실거래에 바로 사용합니다.

B2B API는 어떤 연동을 제공하나요?

시그널 생성, 리스크 관리, 주문 라우팅 엔드포인트를 제공합니다. REST/WebSocket, OAuth2 기반 인증을 지원합니다.
